# Aakhya Engineering Portfolio

A responsive engineering portfolio focused on backend systems, data engineering, distributed systems, and applied AI.

## Live Site

https://aakhya-engineering-portfolio.vercel.app/

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Highlights

- Responsive engineering portfolio
- Custom architecture diagrams
- Reusable project case-study system
- Accessible navigation and reduced-motion support
- Statically generated project routes
- Verified project source links
- SEO and social-preview metadata

## Development

```bash
npm install
npm run dev
```

## Quality

```bash
npm run lint
npm run typecheck
npm run build
```

Profile links are centralized in `src/data/profile.ts`; project content and verified repositories are in `src/data/projects.ts`.
