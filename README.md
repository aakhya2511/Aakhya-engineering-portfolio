# Aakhya Chaudhary — Engineering Portfolio

A standalone, production-ready portfolio built with Next.js App Router, TypeScript, React, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run lint
npm run typecheck
npm run build
```

Verified social, email, and resume URLs can be added in `src/data/profile.ts`. Project content and verified repositories are centralized in `src/data/projects.ts`.
